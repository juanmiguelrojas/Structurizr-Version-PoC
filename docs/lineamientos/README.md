# Lineamientos de Arquitectura como Código (AaC)

Lineamientos **obligatorios** para todos los proyectos de este repositorio. Su cumplimiento se verifica
automáticamente (Agente Revisor, reglas R1–R8) y en la revisión humana de cada PR.

| # | Documento | Contenido |
|---|---|---|
| 01 | [Propósito y alcance](01-proposito-y-alcance.md) | Para qué existe el repositorio, principios y estructura |
| 02 | [Lineamientos de modelado C4](02-lineamientos-c4.md) | Niveles, vistas obligatorias, elementos, relaciones, tags, organización del DSL |
| 03 | [Leyenda oficial C4](03-leyenda-c4.md) | Colores corporativos, fuente única de estilos, regla R7 |
| 04 | [Versionamiento, trazabilidad y seguimiento](04-versionamiento-y-trazabilidad.md) | Carpetas por versión, estados, bitácora, ADR, ramas y commits |
| 05 | [Revisión y aprobación](05-revision-y-aprobacion.md) | Roles, flujo de PR, Agente Revisor, checklist, aprobación de versiones |
| 06 | [Guía de uso de Structurizr](06-guia-structurizr.md) | Herramientas, comandos, sintaxis DSL, artefactos, problemas frecuentes |
| 07 | [Consistencia y calidad](07-consistencia-y-calidad.md) | Convenciones de nombres, *Definition of Done*, consistencia entre proyectos |

Los cambios a estos lineamientos se registran en el [`CHANGELOG.md`](../../CHANGELOG.md) raíz y requieren
aprobación de la Dirección de Arquitectura.
